BongoCat 刷累计点击工具
============
BongCat_main.py是主程序，现在已经添加了窗口,建议在编辑器内运行
博客的方法.py是我在CSDN中找到的方法，给我的程序提供参考让我知道该怎么写才高效
现在可以在窗口中使用它，按F8启动/关闭，ESC键退出。
窗口和模拟按键的点击都是互相独立的所以按F8会直接停止或启动，但窗口可能会产生卡顿

·原理
---------
     F13-F24是IBM时代留下来的按键，F13至F24属于扩展功能键序列，是F1-F12的逻辑延伸，现在的电脑没有这些
     按键，所以使用这些按键几乎不会对日常使用产生影响
     创建多个线程用于模拟F13-F14按键的按下和释放，一个线程10次每秒，总共有11个按键，每一个动作0.025秒
     完整的一次按下和释放就是0.05秒，所以理想情况下每秒110次按下和释放

·已知的问题
-----------
     1.在功能开启时会影响到中英文切换和输入法的切换
     2.单鼠标移到任务栏已打开的窗口图标时，无法正常预览
